# Weakness report

Open **Weakness report** from the home menu, or press `w` in the ranker to
use the selected layout.

The **Report** tab (`1`) lists up to ten metrics where the layout is worse
than the median of its peers, with the peer value and percentile. **Design**
(`2`) explains the selected metric; `g` opens the
[magic designer](MAGIC.md). **Board type** (`3`) picks the peer group by
family (thumb alpha, magic, adaptive, …) and geometry (ortholinear, row or
column stagger, …).

Small peer groups give coarse percentiles. Press `?` for all controls.
